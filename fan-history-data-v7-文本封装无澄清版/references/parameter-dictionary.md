# 风机参数词典与同义词

## 使用原则

- 参数归一只为检索和同口径对比；引用证据时保留原参数名、原值、原单位和原工况。
- 不得仅凭名称相似合并不同工况、不同边界或不同对象。
- 同一参数缺少单位、工况或对象时，先标记不可比或待澄清。
- 未列入词典的参数仍属于历史数据，应通过原文检索保留和引用。

## 单位与工况

- `Nm³/h` 与 `m³/h` 不得直接当成同一数值；需要温度、压力和基准状态才能换算。
- 百分数可能在 Excel 中以 `0.85` 或 `85%` 表示；数据工具统一为 `85`，引用仍保留原文。
- `TB`、`MCR`、`110%MCR`、`70%MCR` 必须作为独立工况处理。
- 噪声必须保留测量距离、是否采取降噪措施、是否含背景噪声等条件。
- 尺寸和重量必须保留“是否含电机/底座/附件”的边界。
- “响应/满足”不是数值，不能进入数值统计。

## 不可自动排序的类别

材质牌号、品牌、结构形式、传动形式、轴承品牌、冷却方式等属于类别数据。除非当前招标文件或已批准专家规则给出明确判断依据，否则历史出现频率或历史评分不能证明某类别更优，也不能形成合规结论。
